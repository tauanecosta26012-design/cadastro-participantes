Este projeto implementa um sistema simples de cadastro de participantes para uma plataforma de eventos geek. A classe Participante representa o molde de cada participante, com os atributos privados nome, email e tipoParticipacao. O encapsulamento foi aplicado tornando os atributos privados e criando métodos getters, setters e um construtor para acessá-los e modificá-los de forma controlada. Foram criados três objetos da classe (Ana - Cosplay, Bruno - Campeonato, Carla - Palestra), cada um com dados próprios. O método exibirInformacoes() apresenta os dados de cada participante sem acessar os atributos diretamente de fora da classe. Os três objetos foram testados executando o método principal, que exibiu corretamente as informações de cada um no console.
